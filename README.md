# Έλεγχος ενεργών πελατών

Τοπική εφαρμογή για Windows που συγκρίνει δύο Excel με **κωδικό πελάτη**:
μητρώο πελατών και αρχείο πληρωμών. Εντοπίζει ενεργούς πελάτες που λείπουν
από τις πληρωμές. Δεν ελέγχει ποσά ή πλήρη εξόφληση.

## Εκκίνηση

Απαιτούνται Python 3.10+ με Tkinter και η βιβλιοθήκη openpyxl.
Στον τρέχοντα υπολογιστή βρέθηκαν Python, Tkinter και openpyxl.

Κάνε διπλό κλικ στο `start.bat`, ή από τον φάκελο του project:

```powershell
python main.py
```

Σε νέο υπολογιστή, εγκατάστησε πρώτα τις εξαρτήσεις:

```powershell
python -m pip install -r requirements.txt
```

## Χρήση

1. Επίλεξε το Excel του μητρώου και το Excel των πληρωμών.
2. Επιβεβαίωσε το φύλλο και τη γραμμή επικεφαλίδων. Μετά από αλλαγή,
   πάτησε «Ανάγνωση φύλλου».
3. Επίλεξε τον κωδικό πελάτη σε κάθε αρχείο, τη στήλη συμβολαίου
   στο μητρώο και προαιρετικά την επωνυμία.
4. Επίλεξε μία ή περισσότερες πραγματικές τιμές που σημαίνουν ενεργό
   συμβόλαιο, π.χ. `Ναι`. Η αρχική αυτόματη επιλογή χρειάζεται επιβεβαίωση.
5. Πάτησε «Έλεγχος». Δες τις καρτέλες «Λείπουν», «Βρέθηκαν»,
   «Άγνωστοι κωδικοί» και «Προς έλεγχο».
6. Εξήγαγε αναφορά Excel με όλες τις εγγραφές, τις ρυθμίσεις και σύνοψη.

Η αναζήτηση φιλτράρει κάθε καρτέλα. Προβάλλονται έως 1.000 αποτελέσματα
ανά φίλτρο για να παραμένει ελαφριά η οθόνη· η εξαγωγή περιέχει όλα.
Η ανάγνωση, σύγκριση και εξαγωγή τρέχουν στο παρασκήνιο.

## Δοκιμή χωρίς πραγματικά δεδομένα

Στον φάκελο `examples` υπάρχουν δύο συνθετικά Excel. Αναδημιουργούνται με:

```powershell
python examples/create_demo.py
```

Με ενεργή τιμή `Ναι`, αναμένονται: **2 βρέθηκαν**, **2 λείπουν**
(`002`, `004`), **1 άγνωστος κωδικός** (`999`) και **1 επιπλέον πληρωμή**
του ίδιου πελάτη. Ο πελάτης `005` είναι ανενεργός.

## Κανόνες και όρια

- Υποστηρίζονται `.xlsx` και `.xlsm`. Μετέτρεψε `.xls` σε `.xlsx` στο Excel.
- Κάθε επιλεγμένο φύλλο πρέπει να περιέχει έναν πίνακα με επικεφαλίδες.
- Κωδικοί συγκρίνονται χωρίς εξωτερικά κενά και χωρίς διάκριση πεζών/κεφαλαίων.
  Εσωτερικά κενά και αρχικά μηδενικά παραμένουν σημαντικά.
- Ο κωδικός `001` είναι διαφορετικός από το `1`. Διατηρούνται οι κωδικοί
  κειμένου και απλές αριθμητικές μορφές όπως `000000`. Χαμένα αρχικά μηδενικά
  από ένα αρχικό αρχείο δεν μπορούν να ανακτηθούν χωρίς κανόνα μήκους.
- Διπλοί κωδικοί στο μητρώο εξαιρούνται από τα οριστικά αποτελέσματα και
  εμφανίζονται για έλεγχο. Αν υπάρχουν πολλά συμβόλαια ανά πελάτη, χρειάζεται
  ξεχωριστός κανόνας αντιστοίχισης ανά συμβόλαιο.
- Πολλές πληρωμές ανά κωδικό επιτρέπονται. Κενός κωδικός ή κενή κατάσταση
  συμβολαίου εμφανίζονται για έλεγχο.
- Οι μη κενές καταστάσεις που δεν επιλέχθηκαν ως ενεργές θεωρούνται μη ενεργές.
- Χρησιμοποιούνται τα αποθηκευμένα αποτελέσματα τύπων Excel. Ανανέωσε και
  αποθήκευσε τα αρχεία στο Excel πριν την εισαγωγή. Δεν εκτελούνται macros.
- Ο έλεγχος αφορά μόνο το αρχείο πληρωμών που επέλεξες. Δεν φιλτράρει μήνα
  ή περίοδο και δεν αθροίζει ποσά.
- Τα δεδομένα επεξεργάζονται τοπικά στη μνήμη. Η εφαρμογή δεν στέλνει αρχεία
  στο διαδίκτυο και δεν αποθηκεύει ιστορικό. Αποθηκεύει μόνο την αναφορά που
  επιλέγεις. Τα αρχικά αρχεία ανοίγουν μόνο για ανάγνωση.
- Δεν υπάρχουν ακόμη λογαριασμοί χρηστών ή εγκαταστάτης `.exe`.

## Δομή για επεκτάσεις

| Αρχείο | Ευθύνη |
| --- | --- |
| `customer_check/models.py` | Κοινά μοντέλα δεδομένων |
| `customer_check/excel.py` | Ανάγνωση Excel και εξαγωγή αναφορών |
| `customer_check/reconcile.py` | Κανόνες σύγκρισης, ανεξάρτητοι από τη διεπαφή |
| `customer_check/desktop.py` | Τοπική γραφική εφαρμογή |

Ο διαχωρισμός επιτρέπει να προστεθούν έλεγχοι ποσών, περίοδοι πληρωμών
και αποθήκευση ιστορικού. Για χρήση από πολλούς συναδέλφους, οι ίδιοι
κανόνες σύγκρισης μπορούν να χρησιμοποιηθούν από web διεπαφή με βάση δεδομένων.
Η τρέχουσα έκδοση κρατά τα επιλεγμένα δεδομένα στη μνήμη· πολύ μεγάλα αρχεία
θα χρειαστούν επιπλέον βελτιστοποίηση.
